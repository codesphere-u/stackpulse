Telemetry & API Reference

OTLP Endpoints, Anomaly Detectors & SLO Windows

POST · /v1/traces

Standard OTLP/HTTP JSON Ingestion

Deserializes OpenTelemetry Collector resourceSpans and normalizes 128-bit/64-bit trace and span IDs.

POST · /api/v1/alerts/register-webhook

SSRF-Hardened Alert Webhook Registration

Registers Slack or JSON alert endpoints while blocking private IPv4/IPv6, localhost, and cloud metadata IPs.

GET · /api/v1/aegis/leaf/{trace_id}

Nexus Aegis G4 Trajectory Leaf

Generates RFC 6962 0x00-prefixed SHA-256 leaf hash certifying critical path and anomaly health.

GET · /api/v1/slo

Multi-Window SLO Compliance Report

Returns 1h, 6h, 24h, and 72h availability/latency burn rates and projected hours to budget exhaustion.

GET · /api/v1/incidents/postmortem

Blameless SRE Postmortem Synthesizer

Correlates trace bottlenecks, structured error logs, and SLO breaches into structured Markdown postmortems.

ANOMALY · N_PLUS_ONE_ORM

N+1 ORM Query Regression Detector

Triggers when ≥4 identical sequential database operations execute under a single parent span.

ANOMALY · RETRY_STORM

Downstream HTTP 503 Retry Storm Detector

Detects repeated consecutive downstream 5xx retries amplifying tail latency.

SLO · PAGE_CRITICAL (14.4x)

Fast-Burn Pager Alert

Pages immediately when 1h burn rate meets or exceeds 14.4x error budget consumption.

SLO · TICKET_WARNING (3.0x / 6.0x)

Slow-Burn Engineering Ticket

Emits warning tickets for sustained 6h/24h/72h error-budget erosion before outage.
