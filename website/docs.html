StackPulse Documentation

Cloud observability, W3C TraceContext DAG critical-path analysis, and SRE SLO reliability platform.

Install OTLP Ingestion DAG Analyzer SRE Burn Rates Aegis G4

1. Installation & Simulation

git clone https://github.com/codesphere-u/stackpulse.git
cd stackpulse
pip install -e ".[dev]"
stackpulse simulate --scenario all --count 24
stackpulse serve --host 127.0.0.1 --port 8098

2. OpenTelemetry OTLP/HTTP JSON Adapter

Send standard OpenTelemetry Collector resourceSpans directly to POST /v1/traces or POST /api/v1/otlp/traces, or batch-load JSON files with stackpulse ingest-otlp -f trace.json.

3. W3C Critical-Path DAG & Exclusive Time

TraceAnalyzer reconstructs trees from out-of-order spans, merges overlapping async child intervals before subtraction, and isolates N+1 ORM queries and 503 retry storms.

4. Multi-Window SRE SLO Burn Rates

SLOEngine computes 1h, 6h, 24h, and 72h burn rates against target SLIs and projects hours until error-budget exhaustion.

5. Nexus Aegis G4 Trajectory Attestation

stackpulse export-aegis
curl -s http://127.0.0.1:8098/api/v1/aegis/leaf/<trace_id>
